# thivalente-skills

Reusable skills for Codex and Cursor.

## Structure

Each skill lives in its own folder:

`skills/<skill-name>/SKILL.md`

## Available skills

- **guided-discovery** — clarifies an open topic through a finite, evidence-based sequence of questions, with a temporary handoff and a final synthesis.

## Installation

### Codex

Copy a skill folder into:

`%USERPROFILE%\.codex\skills\<skill-name>`

### Cursor

Copy the skill's `SKILL.md` into:

`.cursor\skills\<skill-name>\SKILL.md`

## Language

`guided-discovery` follows the language explicitly defined in the initial
prompt. If none is defined, it uses the predominant language of that prompt.
